# 原理图绘制与电路设计指南

## 何时使用
当用户要求新建电路、在现有原理图上添加模块（如电源模块、按键电路、传感器接口、LED 指示等）、绘制导线或连接元件引脚时使用此工作流。

## 标准执行流程

按任务选择必要步骤，不要每次从头扫描图纸与元件库。已有且未改变的查询结果直接复用；
简单补线、改值或局部移动只读取受影响对象。开头一句话说明后就开始工作，避免反复解释计划。

用户要求 LDO、LED、分压、去耦、USB-C 取电或 RS-485 等常见模块时，先检查
`list_circuit_templates` / `preview_circuit_template`；模板合适则提交 `apply_circuit_template`
动作，不必再逐个搜索、放置同一批元件。需要电压、电流等关键参数时明确询问，不要猜测。

以下工具名用于说明流程；具体参数名、类型和枚举值以当前工具 schema 为准。
所有文件修改都通过 `submit_change_plan`，批准后由系统顺序执行，不要再次逐项调用修改工具。

### 1. 勘测图纸与规划区域
1. 新增或移动元件且缺少有效图纸信息时，调用 `get_schematic_sheet_info` 获取尺寸及安全绘图区域。
2. 缺少目标位置或可用位号时，调用 `list_schematic_symbols` 掌握现有元件；已有结果则直接复用。
3. 新增模块时调用 `find_free_area(width, height)` 寻找无重叠的安全矩形空间作为基准坐标 `(base_x, base_y)`。

### 2. 检索符号与放置元件
1. 若不确定符号库名，调用 `search_symbols(query="...")` 查询标准库，以返回的真实库标识为准。
2. 调用 `get_symbol_pins` 获知引脚编号、名称与极性；已有可信结果时不重复查询。
3. 把 `add_symbol_to_schematic` 动作加入计划，指定主芯片/外围器件的真实库标识、参考号、值与位置。
4. 需要时用 `place_symbol_relative` 相对主芯片整齐排布，按工具定义选择方向与间隔。
5. 用 `set_symbol_property` 补齐实际封装与值，封装须与器件和库匹配。
6. 已知参考号及引脚编号时，放置、设置属性和引脚连线可放在同一顺序执行计划中。
   只有后续参数依赖未知的执行结果时才分批；不必每放一个器件都重新列出全图。

### 3. 引脚连接与网络规划
1. **就近引脚连接**：
   - 优先使用 `connect_pins_with_wire`，按 schema 指定参考号和引脚编号；
   - LDO 的 OUT 与输出电容应按实际型号的引脚定义连接，不能套用未经核实的编号。
2. **电源、地与长距离信号**：
   - 避免跨图拉过长的杂乱实线；
   - 在实际引脚或导线端点用 `add_label_to_schematic` 添加网络标签。
   - 同名局部标签的连接有图纸作用域；跨层次图纸须核对标签类型与层次连接。

### 4. 网表校验与同步
1. 调用 `check_reference_conflicts` 确保原理图中无重复参考号。
2. 调用 `extract_schematic_netlist` 检查网络完整性，确认无意外遗漏的 `unconnected_pins`。
3. 仅在实际修改和验证完成后汇报结果，用户可在右侧预览或导出工程。
   用户要求同步 PCB 时，在 Web 中运行 `run_eco_check`，将 `update_pcb_from_schematic`
   加入变更计划，执行后复查 ECO / DRC。不要要求用户打开本地 KiCad 或使用桌面 IPC。

### 5. 遇到错误继续推进
参数错误先依据 schema 修正；检索为空则使用准确型号或换一种搜索方式。
每次修复须有新依据，最多尝试两种合理方法。只重做失败及未执行动作，保留成功结果；
关键条件不足或能力确实不可用时，再说明具体缺口并提问。

## 经验法则
- 原理图坐标系 +Y 向下，必须严格对齐 **1.27 mm (50 mil)** 栅格（KiCad 导线只有在引脚端点精确重合时才能形成电气连接）。
- 旋转只允许 0, 90, 180, 270 度逆时针。
- 电阻、电容、二极管等被动器件必须带有明确的 `Value`（如 `10k`, `10uF`, `0.1uF`）和 `Footprint`。
