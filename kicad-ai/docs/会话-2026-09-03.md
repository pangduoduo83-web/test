## 上游项目调研结论

- 上游是 KiCad 10 的 Action Plugin：wxPython 聊天面板 + 内置 `kcaa` MCP 服务器（FastMCP，100+ 工具：符号/封装库、原理图编辑、PCB 布局/布线/区域、DRC、版本快照、Skill、IPC）。
- `kicad_plugin/llm_client.py` 手写 OpenAI/Anthropic 工具循环、上下文压缩、系统提示（坐标系/硬性规则）。
- `tool_registry.py` 定义 ToolPolicy（query / file_mutation / versioning / ipc_action …，auto_snapshot、mark_dirty）——这是框架级策略的核心，已移植为 `KiCadPolicyMiddleware`。
- 单用户、本地文件、依赖 KiCad GUI（IPC）——需要为 Web 多用户重新设计工作区隔离与持久化。

## 技术选型与验证（deepagents 0.7.13 / langgraph 1.2.11 / langchain 1.3.18）

- `create_deep_agent(model, tools, system_prompt, middleware, subagents, skills, memory, permissions, backend, interrupt_on, context_schema, checkpointer, store)`；
- `CompositeBackend(default=StateBackend(), routes={"/memories/": StoreBackend(namespace=lambda rt: ("memories", rt.context.user_id)), "/skills/": FilesystemBackend(...)})`；
  - 注意：CompositeBackend 会**剥掉路由前缀**再交给子后端，所以 store 里的 key 是 `/AGENTS.md` 而不是 `/memories/AGENTS.md`（已验证，`memory.py` 中 `STORE_KEY`）。
- HITL：`interrupt_on={tool: True}`，中断值为 `HITLRequest{action_requests, review_configs}`，恢复用 `Command(resume={"decisions":[{"type":"approve"|"reject"|"edit"}]})`；
- 流式：`astream(stream_mode=["updates","messages","custom"], subgraphs=True, version="v2")` → 扁平 SSE 事件；
- 持久化：`AsyncSqliteSaver` + `AsyncSqliteStore`（`langgraph-checkpoint-sqlite` 3.1.1），Postgres 可选；
- 工具签名用 `ToolRuntime[AgentContext]` 注入上下文；`functools.wraps` 保留 `__wrapped__` 让 `@tool` 正确推断参数（`_guard` 装饰器）。

### 调研结论（16:55，kcaa 0.2.2 源码）
- 符号侧：`SymbolIndexReader` 只读 **`<config_dir>/sym-lib-table`**（`config_dir` = `KICAD_CONFIG_DIR` 或 `~/.config/kicad/<ver>`），URI 里的 `${KICAD9_SYMBOL_DIR}` 用 `ServerConfig.get_env_vars()` 展开（默认 `<KICAD_APP_PATH>/symbols`，Linux 默认 `KICAD_APP_PATH=/usr/share/kicad`）。`search_symbols` / `add_symbol_to_schematic` / `get_symbol` 全部走 SQLite 索引 `<config_dir>/kcaa/kicad_symbols.db`（`_DEFAULT_DB_PATH` **导入时**算好），**没有索引就搜不到、放不了符号**；索引由 `SymbolIndexManager.sync()` 建，mtime+size 快路径，增量。
- 封装侧：`find_fp_lib_tables()` 找 **`$XDG_CONFIG_HOME|~/.config` / kicad / {10.0,9.0,8.0,7.0} / fp-lib-table**（不认 `KICAD_CONFIG_DIR`），`${KICAD9_FOOTPRINT_DIR}` 同样由 ServerConfig 展开；索引 `<config_dir>/kcaa/kicad_footprints.db`，`search_footprints` 索引为空时会退回慢速实时扫描。
- 两张表都不存在于容器里：KiCad GUI 首次运行才会把 `<app>/template/{sym,fp}-lib-table` 拷进配置目录。所以要**自己种表**。
- kicad-cli：kcaa 用 `shutil.which("kicad-cli")`（`export_tools` / `kicad_cli.py`），我们的 `app/kicad/cli.py` 同样 `which` + `/usr/bin/kicad-cli` 兜底，装好即自动启用（`run_drc_check` 切到 KiCad 引擎、预览 `engine=kicad` 用官方 SVG）。
