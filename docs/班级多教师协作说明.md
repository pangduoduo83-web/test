# 班级多教师协作

班级现在由一名**负责人**和零到多名**协作教师**组成。原有班级的 `teacher_id` 会在 V10 迁移中自动转为负责人，旧班级不需要重新创建。

## 教师能看到什么

加入班级的协作教师可以打开班级详情，查看：

- 班级名称、简介、负责人和协作教师名单；
- 学生名单、学号、专业、加入时间和最近活动时间；
- 每个班级作业的截止日期、说明、报名状态、完成进度和逾期状态；
- 班级公告及发布人。

协作教师还可以加入/移出学生、给全班布置项目、修改作业截止日期和说明、撤销班级布置、发布公告并导出名单与进度。

## 哪些操作只有负责人能做

班级负责人和管理员才可以：

- 修改班级名称和简介；
- 开关学生加入码或重新生成加入码；
- 归档、恢复或删除班级；
- 添加或移除协作教师；管理员可以转交负责人。

协作教师不能删除班级、修改加入码，也不能移除负责人。教师账号可按邮箱、手机号或用户 ID 添加；学生账号和实验室管理员账号会被拒绝。

## 页面入口

教师进入「教师端 → 班级」，打开班级后选择「教师」标签。负责人输入协作教师的邮箱、手机号或用户 ID，点击「加入协作教师」即可。被加入的教师重新进入教师端后，会在「我的班级」看到该班级。
