# AI 成果评审：多材料与 MinerU

## 使用入口

1. 各商户在「管理控制台 → AI 设置」配置本商户的评分模型、图片识别、语音转文字和 MinerU。
2. 教师编辑项目，在高级内容中填写提交要求、默认评分细则；考核项可以覆盖默认细则。细则满分固定100，阶段占项目总成绩的百分比仍由原考核项权重控制。
3. 学生在网页或微信小程序的成果提交页添加图片、视频、PDF、Word。旧版单截图提交仍可读取。
4. 教师在成果评分弹窗启动AI分析，可以关闭页面；重新打开会恢复任务状态和已生成结果。
5. 教师查看每项建议分、依据和需核实事项，通过「填入AI建议」填表，修改确认后再提交成绩。AI任务不会直接修改分数、报名进度或技能画像。

## 每个商户独立配置

配置存入当前商户数据库的 `system_settings`，密钥使用现有 `SecretCrypto` 加密，前端仅回显是否已设置和掩码。部署必须保留 `IOEDU_MASTER_KEY`。不在此文档或代码中填写真实密钥。

| 服务 | 协议与配置 |
| --- | --- |
| 评分模型 | 现有 OpenAI 兼容 `/chat/completions`；需要JSON输出。评分项较多时建议把输出上限设为6000–8000，并提高读取超时。 |
| 图片识别 | 独立地址、模型、API Key；支持 `image_url` 数据URI输入的 Chat Completions。图片以压缩JPEG发送。 |
| 语音转文字（通用） | 接入方式选「通用语音接口」，独立地址、模型、API Key；兼容 `POST /audio/transcriptions`，multipart上传WAV，`response_format=json`，返回 `text`。旧配置默认保留此方式。 |
| 语音转文字（Qwen ASR） | 接入方式选「Qwen ASR（阿里云百炼）」，模型填写 `qwen3-asr-flash` 或其日期版本；向兼容地址的 `/chat/completions` 发送 Base64 WAV `input_audio`，读取 `choices[0].message.content`。 |
| MinerU 官方 | 选择「官方 API」，填服务根地址 `https://mineru.net`、Token、`vlm` 或 `pipeline`，并启用对应配置。 |
| 自部署 MinerU | 选择「自部署」，填服务根地址（不含 `/v1`）、API Key（匿名内网可空）和服务支持的tier，例如 `standard`。 |

两套 MinerU 配置分别保留。使用的协议为：

- 官方精准解析 V4：申请上传链接 → PUT原文件 → 查询批次 → 下载结果ZIP。
- 自部署 MinerU **4.x V1 HTTP API**：`/v1/health`、`/v1/uploads`、完成上传、`/v1/parse/jobs`、`/v1/files/{id}/content`。
- 旧版自部署 `/file_parse` 不是此适配器的协议，部署前应核对版本，不能只换一个地址就假定兼容。
- 不使用免登录轻量解析，也不在失败时退回PDFBox/POI抽文本；PDF和Word均交给所选MinerU。
- 不自动切换服务。未启用、服务不兼容、超时或失败，会在材料状态中明确提示。

### Qwen ASR 配置

在「管理员 → AI 配置 → 多媒体服务 → 视频语音转文字」启用服务，选择 **Qwen ASR（阿里云百炼）**：

- 服务地址：北京地域可填 `https://dashscope.aliyuncs.com/compatible-mode/v1`，也可使用百炼提供的业务空间专属兼容地址。其他地域填写对应地址，并使用相同地域的 API Key；不要填写到 `/chat/completions`。
- 模型名称：`qwen3-asr-flash`，或支持的日期版本（例如 `qwen3-asr-flash-2026-02-10`）。`realtime` 和 `filetrans` 是不同协议，本适配器会在发送音频前明确拒绝。
- API Key：在本商户配置中填写；留空保存会保留已有语音密钥。不会自动使用其他商户或主评分模型的密钥。
- 保存后在一个含讲解的视频成果上点击「AI 分析成果材料」验证语音材料。页面底部的「测试主模型」只测试主评分模型，不代表 ASR 测试成功。

视频仍按每 60 秒切为 16 kHz 单声道 WAV；Qwen 适配器限制每段原始音频不超过 7 MiB，为 Base64 编码后 10 MB 限制留出空间。转写请求使用非流式返回，缺少文字或被截断的结果不会作为成功材料；空字符串可表示无可识别语音。切换语音接入方式会使旧评审材料缓存失效，需重新评审；失败时不会切换到另一协议重发音频。

此项配置使用现有商户设置表，无需增加数据库表或迁移。接口依据：[Qwen-ASR 官方 API](https://help.aliyun.com/zh/model-studio/qwen-asr-api-reference)。

## 文件与处理边界

- 每份成果最多8个附件，单个100MB、合计200MB；文字说明最多2000字。
- 图片：JPG/JPEG/PNG/WebP。WebP转换与视频处理需要FFmpeg。解码后缩小再送模型。
- 视频：MP4/MOV/WebM，自动分析限5分钟，最多均匀抽取8帧；音轨按60秒分段转写。时间戳来自实际截帧位置和音频段起点，不能用抽样未出现的行为判定未完成。
- 文档：PDF、DOC、DOCX。读取MinerU内容列表或结构化结果，保留表格、公式、正文和服务返回的页索引。PDF页码从0基转换为1基；Word转换后的页位置不冒充原文件稳定页码。
- 优先使用结构化结果，若服务仅返回Markdown则明确提示无法可靠定位页码。
- 文档结果最多保留1200块/约30万字；超限提示人工查阅。最终评分模型输入还会按材料分段提供节选，不保证长材料逐字完整送入模型。
- 文档可识别路径的内嵌图片最多分析12张，其余或无法解析的图像块明确提示人工核实。
- MinerU的单文件页数、额度、格式能力仍受所部署服务限制；服务错误不会被当成学生未完成任务。

## 任务、缓存与隔离

- `POST /api/teacher/submissions/{id}/ai-review`（管理员同路径前缀 `/api/admin`）返回任务状态；body可传 `force` 或 `retryAttachment`。
- 同路径 `GET` 查询进度、材料解析状态和结果。教师启动与查询都验证项目归属。
- 单个提交同时进行的请求合并；结果保存到当前商户 `review_jobs`，关闭网页不影响执行。后台工作线程显式绑定租户，结束后恢复上下文。
- 2个工作线程、最多16个待处理任务，避免模型调用无限并发。工作进度和心跳写库。
- 成功的附件解析结果可复用；重试某个附件时保留其他材料。MinerU任务编号会保存，轮询超时后重试优先继续查询原任务。
- 评分标准、模型配置和材料变化会使旧结果显示失效。运行中切换配置会中止后续评审，避免生成混用配置的结论。
- 服务进程重启不自动恢复执行线程；15分钟没有心跳的任务显示中断，重新评审可复用已保存材料。自部署MinerU自身重启也可能丢失任务，需要重试重新提交。
- 新上传附件记录上传者，提交时验证归属；解析仅读取当前商户上传目录，不下载学生提供的任意URL。
- MinerU API密钥仅发送到配置服务的同源地址；预签名跨域上传、下载不附带本系统保存的MinerU密钥。结果ZIP不直接解压到任意磁盘路径，并限制读取大小。

## 部署

1. 发布后端和网页前端；小程序代码需重新构建、提交发布。
2. 启动会通过现有租户迁移机制执行 `V6__multimodal_reviews.sql`，添加附件、评分细则、文件归属与任务表。新增商户同样执行这份迁移。
3. Docker运行镜像安装了FFmpeg。非Docker部署需安装FFmpeg/FFprobe，并使其在PATH中，或设置 `IOEDU_REVIEW_FFMPEG`、`IOEDU_REVIEW_FFPROBE` 为绝对路径。
4. 后端multipart上限调至100MB；仓库Nginx配置调至102MB。如果上游还有其他代理，也要对齐上传大小和超时设置。
5. 分别登录两家测试商户配置不同的模型/MinerU服务，执行实际文件解析和人工确认评分，核实账单与权限后再向用户开放。

## 已有验证与上线前验证

自动化测试使用本地模拟HTTP服务验证官方V4、自部署V1的上传、查询、结果下载、恢复查询，以及密钥隔离；同时验证评分规则、引用校验、ZIP路径/大小边界、文件归属和跨商户后台任务。

本次验证结果：20项后端测试全部通过（无跳过），网页生产构建和微信小程序构建通过。构建仍有现有依赖弃用、网页分包体积提示，不影响本次构建完成。

真实视频测试生成短视频后用本机FFmpeg抽帧，模型部分使用替身；未配置服务账号时不会调用收费接口。

真实MinerU、真实模型和生产数据库迁移仍需部署环境联调，模拟通过不代表某个商户提供的服务地址一定兼容。

## 配置页面独立测试（2026-09-21）

- 主模型、图片识别、语音转写以及当前选择的 MinerU 服务各有独立的测试按钮、加载状态和结果。主模型失败不阻止其他服务测试。
- 测试使用表单当前填写的地址和模型，不自动保存或启用配置；密钥留空只复用当前商户该服务已保存的密钥。修改服务域名、端口或协议后须重新输入对应密钥，避免把已保存密钥发送到另一服务。
- 图片测试提交内置的几何图形 JPEG；语音测试提交约 3.6 秒的合成中文 WAV。不会使用学生材料，也不会创建成果评审任务。模型服务商可能按实际调用计费。
- MinerU 官方服务测试验证 Token 并申请一个测试上传链接，不上传文件或启动解析；自部署服务测试检查 `/v1/health` 的 ZIP 输出能力。连接测试成功不等于真实报告解析成功。
- 新接口：`POST /api/admin/ai-settings/test/{service}`，`service` 为 `main`、`vision`、`speech`、`mineruCloud`、`mineruLocal`。请求字段为 `baseUrl`、`model`、可选 `apiKey`，语音另传 `speechProtocol`；仅管理员可用。原主模型测试接口保留兼容。
- 修改配置会清除该服务的旧测试结果；如果请求尚未结束，其过期结果不会覆盖修改后的表单。401、404、429 等错误分别提示密钥、接口地址及额度问题，不回显服务商原始错误内容。
