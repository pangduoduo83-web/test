## 当前存储开关

```dotenv
STORAGE_TYPE=oss
OSS_BUCKET=ioedu-files-prod
OSS_REGION=cn-beijing
OSS_ENDPOINT=https://oss-cn-beijing.aliyuncs.com
OSS_DIRECT_UPLOAD=true
CDN_DOMAIN=https://files.labcloud.com.cn
CDN_AUTH_SECONDS=7200
VIDEO_HLS=false
```

当前 Bucket 私有；新文件存入 OSS。`files.labcloud.com.cn` 已配置为阿里云 CDN 加速域名，启用 HTTPS、同账号私有 Bucket 回源、Type A URL 鉴权、Range 回源和 CNAME。服务器使用同一枚鉴权密钥生成 7200 秒签名地址，公网实测未签名请求 403、签名请求 200、Range 请求 206，后端文件链接会重定向到 CDN；主站 Origin 的 CDN CORS 响应也已验证。证书由服务器上的 Let’s Encrypt 证书签发，有效期至 2026-12-20；到期前需要把续签后的证书重新上传到 CDN。

浏览器直传已开启：主站、IP 和分站跨域已验证，真实 API 凭证、OSS POST、确认幂等及文件读取测试通过，测试对象已清理。OSS 控制台已为 `ioedu/staging/` 配置最后修改后 1 天删除的生命周期规则，正式对象目录不受影响。HLS 代码已部署但仍保持 `VIDEO_HLS=false`，需要额外开通 IMM、配置处理角色和 CDN 边转边播回源规则后再启用。详细步骤见 [OSS存储升级说明](OSS存储升级说明.md)。

```bash

```
