# AI未来实践中心 - 微信小程序端(学生/教师/管理员三端)

基于 **uni-app (Vue 3 + Vite)** 的微信小程序,完整复刻网页版学生端功能,并集成教师端与管理员端(按登录角色在「我的」页展示入口),直接复用现有 Spring Boot 后端 `/api` 接口,后端零改动。

## 功能清单

### 学生端

| 模块 | 说明 |
|---|---|
| 登录/注册 | 邮箱+密码,注册含姓名/学号/专业/年级,演示账号一键填充(学生/教师/管理员) |
| 项目中心(Tab) | 关键词搜索、排序(热度/评分/最新/下载)、难度/分类筛选 |
| 项目详情 | 概览/技能要求(对比我的技能)/所需设备/教学大纲/BOM/学习资源/讨论区,报名、收藏、分享 |
| 成果提交 | 已报名项目可提交成果说明+截图,查看评分与评语;≥60 分自动判定项目完成 |
| 设备图书馆(Tab) | 搜索、状态/位置/评分/分类筛选、库存展示 |
| 设备详情 | 规格/适用项目/文档,底部申请借阅 |
| 借阅申请 | 三步流程:填写(数量/目的/日期/时长/协议) → 确认 → 出申请单号 |
| 借阅管理(Tab) | 统计卡、状态筛选、撤销申请、申请归还,状态机与网页版一致 |
| 我的(Tab) | 等级经验条、统计四宫格、学习趋势图(周/月,时长/任务)、进行中项目(可推进+10%)、成就徽章 |
| 技能评估 | canvas 雷达图、六维明细、个性化建议、滑块自测评 |
| AI 学习规划师 | 技能页一键生成:学习画像总结 + 重点提升维度 + 三阶段项目路线(未配置 AI Key 时自动降级为智能匹配) |
| 其他 | 站内通知(已读/全部已读)、编辑资料(含头像上传)、修改密码 |

## 开发运行

```bash
cd miniprogram
npm install          # 已配置 .npmrc(legacy-peer-deps)
npm run dev:mp-weixin
```

然后打开 **微信开发者工具** → 导入项目 → 选择 `miniprogram/dist/dev/mp-weixin` 目录(AppID 可用测试号)。dev 模式下保存代码即增量编译,开发者工具会自动刷新。

### 联调后端

1. 启动后端(默认 8080)与 MySQL,见根目录 README。
2. `src/config.js` 中 `BASE_URL` 默认 `http://localhost:8080`:
   - 开发者工具本机联调:在「详情 → 本地设置」勾选 **不校验合法域名**即可;
   - 真机预览:把 `BASE_URL` 改为电脑局域网 IP(手机与电脑同一 WiFi);
   - 若 8080 被其他程序占用,改后端端口的同时同步修改 `BASE_URL`。

## 发布构建

```bash
npm run build:mp-weixin   # 产物在 dist/build/mp-weixin
```

用微信开发者工具导入 `dist/build/mp-weixin`,替换 `src/manifest.json` 中 `mp-weixin.appid` 为你的正式 AppID,后端需部署为 HTTPS 并在微信公众平台配置 request/uploadFile/downloadFile 合法域名。

## 技术说明

- 鉴权:登录后 token 存本地,所有请求带 `Authorization: Bearer <token>`;任何接口返回 401 时自动清登录态并回登录页。
- 响应:统一按后端 `{ code, message, data }` 包装解包,`code === 0` 视为成功。
- 图片:后端相对路径(`/uploads/...`)自动拼 `BASE_URL`;种子数据的 Unsplash 外链直接展示。
- 雷达图/趋势图:原生 canvas 2d 与纯 CSS 实现,未引入图表库。
